# JL Physio
Design Studio WS2026 - Projekt von Natalie Neumayer

---

JL Physio wird ein webbasiertes Physiotherapie-Programm, das meiner Auftraggeberin und ihren Patient:innen ermöglicht, den individuellen Prozess der Physiotherapie zu digitalisieren und aktiv am Home-Training teilzunehmen.

---

## Konzept & Ziele

Das Programm basiert auf einem zweiseitigen Login-Modell (Login 1 - Therapeutin & Login 2 - Patient:in), das auf die unterschiedlichen Bedürfnisse der beiden Parteien ausgelegt ist.

**Die Therapeutin**
kann individuelle Übungspläne erstellen, zuweisen und bearbeiten, Pläne für technikfremde Patient:innen als einheitlich formatierte PDF erstellen und einen allgemeinen Übungskatalog warten und erweitern. Zudem soll es für sie möglich sein, Feedback ihrer Patient:innen einzusehen.


**Die Patient:innen**
können ihren persönlichen täglichen Übungsplan mit Kurzanweisungen (und bestenfalls KI-Avatar-Bildern) einsehen und diesen Plan step-by-step abarbeiten. Zudem soll es für sie möglich sein, Feedback zu geben.

---

## Technische Details

* **Frontend:** (Responsive) Web-Application (Desktop und bestenfalls Mobilgeräte) - HTML, CSS, JS
* **Backend:** Relationale SQL-Datenbank via Supabase mit logischer Verknüpfung von Benutzerrollen, Übungskatalog, Übungsplänen (und Feedbacks) - PostgreSQL
